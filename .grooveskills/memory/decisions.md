| 2026-11-03 | Architectural Wrapper & Adapter Skills Suite | Added 6 architectural skills (`storage-file-adapters`, `auth-rbac-policies`, `controller-orchestration-queues`, `webhook-idempotency`, `caching-rate-limiting`, `env-feature-flags`) | Standardizes object storage, auth/policies, single-purpose action orchestration + queue workers, HMAC webhook verifiers + idempotency, cache-aside + rate limiting, and fail-fast env validation across projects |
| 2026-11-03 | Documentation Standards Skill (`docs-standards`) | Added unified documentation skill covering English documentation, relative POSIX paths, Mermaid diagrams, ADR lifecycle, and intent docstrings | Establishes standard technical documentation practices, eliminates absolute path breakage across IDEs, ensures syntactically safe Mermaid diagrams, and enforces intent-driven docstrings |
| 2026-11-03 | Defensive File Permissions & Transactional Rollback (v1.7.0) | Implemented `safeWriteFileSync` with auto-chmod (0o644) on EACCES/EPERM, `InstallTransaction` journaling, and structured error handling | Prevents dirty/partial repo states on permission issues (like read-only `AGENTS.md`), auto-recovers writable mode when permissible, and rolls back mutations on failure |
| 2026-11-03 | Escalating Atomic Replace, Preflight Write Check & English CLI (v1.7.1) | Added `inspectFileAccess`, atomic file replacement (`temp + rename`) in `safeWriteFileSync` for root-owned files in writable directories, `runPreflightWriteCheck`, honest rollback failure tracking (`isClean` / `failures`), and restored 100% English CLI copy | Resolves `EACCES` when `AGENTS.md` is owned by `root` in a user-writable directory without requiring `sudo chown`, fails before Stage 1 when recovery is impossible, avoids rewriting untouched files on rollback, and keeps CLI output strictly in English |
| 2026-11-03 | Universal Descriptive Naming Standard | Added Golden Rule #8 to `best-practices` prohibiting single-/two-letter and cryptic identifiers (`d`, `a`, `s`, `p`, `tx`, `err`, `res`) across codebases | Ensures maximum legibility, zero ambiguity in callbacks and loops, and enforces explicit domain intent in all codebases managed by GrooveSkills |
| 2026-11-08 | Mandatory README Updates on Scope Changes | Standardize mandatory README.md synchronization whenever functionality, CLI commands, flags, or project structure are added or removed | Keeps user-facing documentation aligned with code changes in real-time, preventing stale guides, obsolete CLI documentation, or outdated directory structures |
