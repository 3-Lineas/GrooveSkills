# Guía Rápida de Patrones de Copy (ES / EN)

Diccionario y patrones de microcopy persuasivo, empático y profesional para interfaces modernas.

---

## 1. Acciones y Botones (CTAs)

| Acción | ❌ Genérico / Frío | ✅ Español Persuasivo | ✅ English Benefit-Driven |
| :--- | :--- | :--- | :--- |
| Enviar formulario | Submit / Enviar | Continuar / Comenzar ahora | Continue / Get started now |
| Guardar cambios | Guardar / Save | Guardar cambios | Save changes |
| Crear recurso | Crear / Create | Crear nuevo proyecto | Create new project |
| Registrarse | Registrar / Register | Crear mi cuenta gratis | Create free account |
| Iniciar sesión | Login | Entrar a mi cuenta | Sign in to my account |
| Cancelar proceso | Cancelar | Descartar cambios | Discard changes |
| Eliminar permanente | Eliminar / Delete | Sí, eliminar permanentemente | Yes, delete permanently |
| Actualizar plan | Upgrade | Mejorar mi plan | Upgrade my plan |

## 2. Mensajes de Validación de Formularios

| Regla | ❌ Evitar | ✅ Español Amable | ✅ English Clear |
| :--- | :--- | :--- | :--- |
| Campo requerido | Requerido | Este campo es necesario para continuar. | This field is required to continue. |
| Email inválido | Formato inválido | Ingresa un correo válido (ej: hola@tuweb.com). | Enter a valid email (e.g. name@company.com). |
| Teléfono inválido | Número erróneo | Ingresa un número de 9 a 12 dígitos sin espacios. | Enter a 10-digit phone number. |
| Contraseña corta | Muy corta | Usa al menos 8 caracteres para mayor seguridad. | Use at least 8 characters for stronger security. |
| Confirmar clave | No coincide | Las contraseñas deben ser idénticas. | Passwords do not match. Please verify. |
| Archivo pesado | Archivo muy grande | El archivo supera el límite de 10 MB. Elige uno más liviano. | File exceeds 10 MB limit. Please select a smaller one. |
